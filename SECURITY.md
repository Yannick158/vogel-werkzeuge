# Reporting a security problem

Thank you for looking. This repository describes how a Raspberry Pi in a
private home talks to a public server, so a mistake in it can have real
consequences for whoever is running it.

## Please report privately

Use GitHub's **[private vulnerability
reporting](https://github.com/Yannick158/vogel-werkzeuge/security/advisories/new)**
— the "Report a vulnerability" button on the Security tab. It reaches me
without anything becoming public, and without either of us having to publish
an email address.

Please do **not** open a public issue for a security problem. People run this
on machines that are reachable from the internet; a public issue tells them
and everyone else at the same moment.

## What is in scope

Anything in this repository, in particular:

- **`server/briefkasten/`** — the mailbox. It is the only thing the Pi pushes
  into and the only thing the website reads from. Path traversal, unbounded
  writes, or any way to make it reach *outward* would matter.
- **`server/eigenes/`** — the live view and the app endpoints, including
  `live.php` and everything under `app/`.
- **`server/push/`**, **`server/wochenschau/`** — anything that handles
  subscriptions, device tokens, or builds command lines.
- **`bereitstellung/`** — the Caddy configuration and the hardening script.
  Advice that is simply wrong belongs here too, not only code.
- The architectural claim itself: **the Pi pushes, nothing pulls.** If you can
  show a path from the public internet into the home network, that is the most
  valuable report you can make.

## What is out of scope here

- **BirdNET-Pi, AvianVisitors and the BirdNET model.** They are separate
  projects and none of their code is in this repository. Report those to
  [Nachtzuster/BirdNET-Pi](https://github.com/Nachtzuster/BirdNET-Pi),
  [Twarner491/AvianVisitors](https://github.com/Twarner491/AvianVisitors) or
  the [BirdNET team](https://birdnet.cornell.edu) respectively.
- Findings that require physical access to the Pi, or an attacker who already
  has the operator's SSH key.
- Reports generated by a scanner without a described path to impact.

## What to expect

One person, one garden, no company behind it. I will confirm within a few
days and tell you honestly whether I can fix it, when, and whether the fix
will be complete or a mitigation. If a report leads to a change, you get
credit in the commit unless you would rather not.

If something is broken but not a security problem, a normal
[issue](https://github.com/Yannick158/vogel-werkzeuge/issues) is the right
place and very welcome.
